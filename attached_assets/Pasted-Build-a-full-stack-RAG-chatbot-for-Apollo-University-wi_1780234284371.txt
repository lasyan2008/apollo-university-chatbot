## RAG PIPELINE

### Embeddings Service (server/services/embeddings.js)
- Use @xenova/transformers pipeline
- Model: Xenova/all-MiniLM-L6-v2
- Function: generateEmbedding(text) → returns 384-dim vector

### Pinecone Service (server/services/pinecone.js)
- Connect using PINECONE_API_KEY
- Index: apollo-university
- Function: queryPinecone(vector, topK=5, filter={branch_id}) → returns matches
- Each document chunk stored with metadata: { branch_id, school_id, source_file, chunk_index }

### Groq Service (server/services/groq.js)
- Use groq-sdk package
- Model: llama3-8b-8192
- System prompt:
  "You are Apollo University's official academic assistant. 
  Answer questions based ONLY on the provided context from the university's 
  official documents. If the answer is not in the context, say 
  'I don't have information about this in the current documents. 
  Please contact the university directly.' 
  Be helpful, accurate, and concise. Format answers clearly."
- Function: generateAnswer(question, context) → returns answer string

### Chat Route (server/routes/chat.js)
POST /api/chat
Body: { question, branch_id, school_id }
Steps:
1. Generate embedding for question
2. Query Pinecone with embedding + filter by branch_id
3. Also query with filter by "academic_calendar" for general questions
4. Build context from top 5 matches
5. Send to Groq with system prompt + context + question
6. Return { answer, sources: [source_file names] }

## DOCUMENT UPLOAD SCRIPT (scripts/uploadDocs.js)
- Read all .txt files from /docs folder recursively
- For each file:
  - Extract branch_id from folder path (e.g. docs/SOT/btech_aiml.txt → branch_id: btech_aiml)
  - Extract school_id from folder name (e.g. SOT)
  - Chunk text into 500 character chunks with 50 character overlap
  - Generate embedding for each chunk
  - Upload to Pinecone with metadata: { branch_id, school_id, source_file, chunk_index, text }
- Show progress: "Uploading chunk X of Y from filename..."
- Run with: node scripts/uploadDocs.js
